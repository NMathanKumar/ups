# Employee AI Digital Assistant

A hackathon MVP that provides employees with a unified conversational interface for accessing information across multiple enterprise systems.

## MVP Architecture

React Frontend
→ API Gateway
→ AWS Lambda
→ Amazon Bedrock
→ RAG Knowledge Base
→ S3

Lambda
→ DynamoDB

## Enterprise Sources

- HR
- IT Support
- Learning
- Onboarding

## MVP Innovation

Policy-to-Action assistance: the system not only answers employee questions using enterprise knowledge, but can identify actionable requests and create employee reminders.
